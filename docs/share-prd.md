# 公开分享链接 PRD（V2 第二期）

> 状态：已实现　｜　关联：`docs/account-sync-prd.md`

## 背景与问题

投递时经常需要直接发一个链接给 HR 或朋友，而不是附件。分享链接必须满足：只读、可撤销、可设置访问密码与有效期、不暴露账号信息、失效后立即不可访问。

## 目标

- 登录后可把当前简历生成只读公开链接 `/r/<token>`
- 链接展示**创建/更新时的快照**，后续本地编辑不会自动改变已分享内容
- 支持「更新内容」重新快照，支持「撤销分享」立即失效
- 支持可选访问密码（bcrypt）与有效期（7 / 30 / 90 天 / 永久）
- 带密码的分享在解锁前不返回简历内容，只返回密码表单
- 分享页不显示用户邮箱、账号或编辑入口；`noindex`
- 复用现有模板渲染与打印样式，分享页可直接打印为 PDF

## 非目标

- 访问统计、自定义 slug、多个不同分享
- 访客留言 / 互动
- 密码找回（分享密码由作者自行保存，丢失后可在管理面板重设）

## 用户故事

| # | 故事 | 验收信号 |
|---|---|---|
| S1 | 我想把简历链接发给 HR | 登录后创建链接，复制即可打开 |
| S2 | 我改完简历想更新分享 | 点「更新内容」，链接不变、内容更新 |
| S3 | 我不想公开了 | 撤销后原链接返回 404 |
| S4 | 访客没有账号 | 无 Cookie 打开链接仍可查看 |
| S5 | 我想限制访问 | 设置密码后，未解锁页面不出现简历内容 |
| S6 | 我想让链接自动失效 | 设置有效期，过期后返回 404 |

## 数据模型

```sql
shares(
  token text PK,
  user_id uuid UNIQUE FK users(id) ON DELETE CASCADE,
  title text,
  doc jsonb,
  password_hash text,
  expires_at timestamptz,
  created_at timestamptz,
  updated_at timestamptz
)
```

- `user_id` 唯一：一个账号一个分享链接
- token：18 字节随机值，base64url，约 24 字符
- 保存快照而非引用 `resumes`：分享内容稳定、可独立更新
- 密码与有效期可在不更换 token 的情况下更新

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/share` | 当前账号的分享信息（token / 有密码 / 有效期） |
| POST | `/api/share` | 创建或更新；`password`、`expiresInDays` 可选 |
| DELETE | `/api/share` | 撤销分享 |
| POST | `/api/public/share/<token>` | 校验密码并返回简历；无密码时也可解密数据 |
| GET | `/r/<token>` | 公开只读页面；不存在、过期或密码未解锁时按情况返回 404 / 密码页 |

- 管理接口要求登录；公开接口不读取会话
- POST `/api/share` 校验 `ResumeDoc`；限流 30 次 / 10 分钟
- 解锁接口按 IP + token 限流 10 次 / 10 分钟
- 页面 `force-dynamic`，`robots: noindex, nofollow`

### 更新语义

- `password` 省略：保留原密码
- `password: null`：移除密码
- `password: "..."`：设置或更换（4–72 字节）
- `expiresInDays` 省略：保留原有效期
- `expiresInDays: null`：永久有效
- `expiresInDays: 1–365`：从现在起计算到期时间

## 前端交互

- 云端面板登录后显示「分享链接」区块
- 未分享：可选密码、选择有效期、`创建分享链接`
- 已分享：只读链接 + `复制`、`更新内容`、`撤销分享`
- 「分享设置」折叠区：设置/更换/移除密码，调整有效期
- 内容超出一页时，创建/更新内容前提示将按一页裁切
- 分享页：无密码直接渲染；有密码先显示密码表单，解锁后客户端接收快照并渲染
- 顶部 `打印 / 保存 PDF`；移动端按容器宽度缩放 A4

## 安全与隐私

- token 高熵且不可枚举；撤销即删除记录
- 快照只包含 `ResumeDoc`，不包含用户邮箱、账号 id、其他简历
- 密码 bcrypt cost 10，数据库中不存明文
- 解锁接口限流，错误密码统一返回 401
- 公开页无编辑入口、无写接口
- 不记录访客信息；无第三方分析

## 边界与异常

| 场景 | 行为 |
|---|---|
| 未登录管理分享 | 401 |
| token 非法或不存在 | 404 |
| 分享已过期 | 404（服务端与解锁接口双重判断） |
| 撤销后访问 | 404 |
| 密码错误 | 401「访问密码错误」 |
| 密码分享未解锁 | 页面只含密码表单，HTML 中不含简历内容 |
| 内容超出一页 | 创建前提示按一页裁切 |
| 更新分享 | token 不变，`updated_at` 刷新 |
| 数据库不可用 | 500，已有链接暂时不可访问 |

## 验收标准

- [ ] 登录后创建分享，返回 `/r/<token>` 链接
- [ ] 无 Cookie 的独立浏览器上下文可打开分享页并看到简历内容
- [ ] 分享页不出现用户邮箱与编辑控件
- [ ] 设置密码后，页面 HTML 不包含简历姓名/内容；错误密码 401，正确密码返回快照
- [ ] 设置 7 天有效期后，接口返回具体到期时间
- [ ] 移除密码后页面恢复直接展示
- [ ] 更新内容后 token 不变、页面内容更新
- [ ] 撤销后原链接返回 404
- [ ] 分享页可打印为单页 PDF
- [ ] `npm run verify` 覆盖创建、公开访问、密码、有效期、撤销
