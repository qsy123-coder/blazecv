# BlazeCV 产品路线图

> 更新：2026-11-16　｜　当前阶段：V2 已完成多页、多简历、版本历史、账号、云同步、分享
> 关联：`docs/resume-builder-prd.md`、`docs/account-sync-prd.md`、`docs/share-prd.md`、`docs/multi-resume-version-prd.md`、`docs/multi-page-prd.md`

## 1. 当前基线

### 1.1 页面与入口

| 路径 | 说明 |
|---|---|
| `/` | 模板市场首页：48 套精选/生成模板、7 种版式、分类/用途筛选、模板创建新简历 |
| `/templates` | 全部模板库：4127 套采集模板、3122 张原预览图、筛选/搜索/分页 |
| `/resumes` | 我的简历：缩略图、搜索、打开、复制、删除、当前标记 |
| `/editor` | 编辑器：`?id=<resumeId>`、`?template=<templateId>` |
| `/r/<token>` | 公开只读分享页：分页、打印、密码保护、失效 |
| `/api/auth/*` | 注册、登录、退出、当前用户 |
| `/api/resumes*` | 云端多份简历：列表、读取、保存、删除 |
| `/api/share` | 分享管理：创建/更新、密码、有效期、撤销 |
| `/api/public/share/<token>` | 分享解锁，校验密码后返回快照 |

### 1.2 已交付能力

- 48 套模板、7 种版式；内容检查评分与模块定位
- 多份本地简历；点击模板创建空白新简历
- 版本历史：每 10 分钟自动保留、最多 20 个、手动保存/恢复/删除
- 多页排版：测量式自动分页、模块/条目/段落拆分、多页 PDF、逐页 PNG、分享页分页
- 账号：邮箱密码、bcrypt、哈希会话、限流、可选云同步
- 云端多份简历：`(user_id, id)` 复合主键、列表/载入/删除
- 分享：只读快照、访问密码、7/30/90 天有效期、撤销即 404
- 本地优先：IndexedDB 自动保存、JSON 备份、离线可用
- 自托管：Next.js standalone + Postgres（PGlite 本地兜底）+ nginx

### 1.3 质量基线

- `npm run typecheck`、`npm run build` 通过
- `npm run verify`：43 项 CDP 回归全过
- 覆盖：模板创建、简历库、多页、版本、导出、离网、多标签、账号、云端隔离、分享密码/撤销

## 2. 优先级原则

1. **留存优先**：同步可靠性、云端版本、冲突不丢数据
2. **交付质量**：分页、打印、导出、可编辑版本
3. **安全前置**：支付之前补齐找回密码、邮箱验证、会话管理
4. **增长随后**：分享统计、模板 SEO、邀请
5. **商业化**：Pro 模板与权益校验，服务端强制
6. **AI 最后**：成本、隐私、可关闭，不阻塞主流程

## 3. 里程碑

### M1 同步与可靠（约 2 周）

**目标**：换设备打开即最新，历史版本可跨端恢复，双端编辑不静默覆盖。

| 事项 | 范围 | 验收 |
|---|---|---|
| 云端自动同步 | 登录后保存防抖上传、同步状态、失败重试、手动开关 | 换设备打开为最新版本；失败可见 |
| 云端版本历史 | `cloud_versions(user_id, resume_id, id, doc, saved_at)`；与本地相同的 10 分钟/20 个策略 | 云端可列出并恢复版本 |
| 冲突处理 | 比较本地/云端 `updatedAt`；冲突时提示「保留本地 / 使用云端」 | 双端同时编辑不丢内容 |
| 简历库同步标记 | 每张卡片显示「本地 / 已同步 / 有未上传修改 / 有云端更新」 | 状态与实际一致 |
| 同步 API | `GET/PUT /api/resumes/<id>/versions`、`GET /api/sync/state` | 接口校验归属与大小 |

**技术要点**
- 保留 last-write-wins 作为默认，但写入前比对版本号/时间戳
- 云端版本与本地版本共用 `ResumeDoc` 校验
- 断网时队列化，恢复后重试；不阻塞编辑

**风险**
- 同一 ID 的并发写入；需要服务端 `updated_at` 条件更新或显式冲突返回
- 版本体积：限制单版本 1MB，版本数 20

### M2 交付质量（约 1.5 周）

**目标**：多页简历可控、可打印、可管理。

| 事项 | 范围 | 验收 |
|---|---|---|
| 手动分页 | 模块前插入分页符、移除分页符 | 预览与 PDF 断点一致 |
| 页码与页眉 | 页码格式、是否显示、页眉文案 | 分享与打印生效 |
| 孤行控制 | 标题不与正文分离；条目尽量不跨页 | 抽查无孤标题、无单行尾页 |
| 简历库增强 | 标签、排序（更新时间/标题）、批量导入 JSON、最近编辑 | 20 份以上可管理 |
| 多页导航 | 缩略图侧栏、页码跳转 | 3 页以上快速定位 |
| 导出增强 | PDF 元数据、文件名规则、批量导出 | 多份简历可批量导出 |

**技术要点**
- 分页器增加 `breaksBefore` 与 `keepWithNext`，在测量阶段纳入约束
- 页码与页眉放在页面框架层，不进入 `ResumeDoc`
- 标签/排序属于本地元数据，云端可后续同步

### M3 安全与增长（约 2 周）

**目标**：账号可自助恢复；分享可度量；模板可被搜索。

| 事项 | 范围 | 验收 |
|---|---|---|
| 修改密码 | 当前密码校验、强度规则、退出其他会话 | 修改后旧会话失效 |
| 邮箱验证 | 验证令牌、过期、重发限流 | 未验证账号限制云同步 |
| 找回密码 | SMTP 邮件、一次性令牌、重置页面 | 10 分钟内完成重置 |
| 会话管理 | 设备列表、撤销单设备、全部退出 | 可踢出旧设备 |
| 分享统计 | 访问次数、最近访问、来源（不含个人信息） | 作者可见统计 |
| 分享增强 | 二维码、OG 图、分享页下载 PDF | 微信/社交预览正常 |
| 模板 SEO | 模板详情页、分类落地页、结构化数据 | 可被搜索引擎索引 |

**依赖**
- SMTP/邮件服务（Resend、SES、自建 Postmark 等）
- 域名与 HTTPS（`COOKIE_SECURE=true`）

### M4 商业化（约 2 周）

**目标**：免费可用，Pro 可付费；权益在服务端校验。

| 事项 | 范围 | 验收 |
|---|---|---|
| 权益模型 | 免费 / Pro；模板、去水印、导出次数、云版本 | 服务端返回权益，前端只展示 |
| Pro 模板 | 3–5 套高级模板、标记与试用 | 未付费试用有次数限制 |
| 支付 | 订阅或按次；订单、回调幂等、退款记录 | 支付成功即时生效 |
| 对账 | 订单状态、失败重试、发票信息占位 | 可与支付渠道对账 |

**原则**
- 不在客户端做权益判断
- 支付回调验签、幂等键、重复通知安全
- 免费版保留完整编辑与 PDF 导出，付费点放在模板/去水印/云版本/批量

### M5 AI 与工程化（持续）

| 方向 | 范围 | 验收 |
|---|---|---|
| AI JD 匹配 | 粘贴 JD → 关键词覆盖、匹配度、缺口 | 结果可解释，可关闭 |
| 要点改写 | 选中要点 → 动作动词/量化建议 | 不自动覆盖，需确认 |
| 成本与隐私 | 明确告知、按次限额、失败降级 | 不阻塞本地编辑 |
| Docker | Compose 实跑、Postgres 迁移演练、备份恢复 | 一台干净服务器可上线 |
| CI | typecheck/build/verify、迁移检查 | PR 必过 |
| 单测 | 分页器、版本策略、诊断规则、文档 schema | 核心逻辑覆盖 |
| 视觉回归 | 48 套模板基线截图 | 模板改动可对比 |
| 可访问性 | 键盘操作、对比度、焦点 | Lighthouse a11y ≥90 |

## 4. 推荐执行顺序

```
M1 同步与可靠  →  M2 交付质量  →  M3 安全与增长  →  M4 商业化  →  M5 持续
```

- M1 与 M2 可部分并行：同步后端与分页前端互不阻塞
- M3 的「账号安全」必须先于 M4 支付
- M4 的 Pro 模板可以先做设计，但权益校验必须等服务端
- M5 的 Docker/CI 建议从 M1 开始并行推进

## 5. 待产品/运营输入

| 事项 | 需要的决定 |
|---|---|
| 邮件服务商 | SMTP 提供方、发件域名、退信处理 |

| Pro 模板 | 数量、风格、是否外包设计 |

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 云端并发冲突 | 内容覆盖 | 时间戳比较 + 冲突提示 + 云端版本 |
| 邮件服务不可达 | 无法找回密码 | 重试队列、备用通道、管理员重置 |
| 支付回调重复 | 重复开通/扣款 | 幂等键 + 订单状态机 |
| 分页字体差异 | PDF 与预览页数不同 | 统一字体栈；打印前自查 |
| PGlite 单进程 | 多实例数据不一致 | 生产强制 Postgres |
| AI 成本失控 | 账单与延迟 | 限额、缓存、可关闭、降级到本地规则 |
