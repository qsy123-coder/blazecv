## 结论

编辑器已接入原站模板页的**真实 DOM + CSS**，不再只靠 `format_info` 映射。4127 套模板页全部抓取成功，字段与条目实时绑定，编辑器/分享页/PNG/PDF/Word 共用同一渲染。

**渲染高度规则（关键）**：原站封面缩略图与下载件都是 `.main.image { height:max-content!important; min-height:297mm }` 的**自然高度渲染**——短内容按一页 A4（1123px），长内容按内容高度（可高于 A4，如 1157/1266px）。本项目按同一规则渲染：`pageHeight = max(1123, 自然内容高度)`，**绝不压缩/拉伸到 A4**。此前将内容压缩进 1123px 是导出与封面不一致、素材错位的根因，已废弃。

基准说明：

- **验收基准 = 原站页面 DOM/CSS 在浏览器中的自然高度渲染**（`jianlimoban/<token>.html` 的 `#cv-container` + 13 个 CSS 分片，794px 宽，自然高度）。
- **原站封面缩略图**（720px WebP）与页面 DOM 是同一渲染的缩放版；由于其宽度不同会产生亚像素差，仅作辅助参照，不作为逐像素基准。经实测，页面自然高度渲染与封面高度在 794px 宽度下平均误差仅约 5.7px。

## 语义绑定

`src/lib/exact-template.ts` 依据原站渲染器稳定类名绑定：

- 头部：`.user-name`、`.profile-item > span`、`.user-avatar-image`
- 模块：`.option.personal_summary / works / edus / project_experience / orgs / honor / extras / custom`
- 条目：`.section-item-container` 克隆/删除，`.menu-title .left/.right`，`.menu-content ul li`
- 技能/语言/自定义：`.extras-icon-item` 或 `li.extras-item`，保留模板图标；技能行使用受采样的原始合并字符串（分隔符 `，`/`, `/`,` 因模板而异，按原样输出）；`li.extras-item` 保留 `font_w_b` 粗体标签 + 值两段结构

- 条目底部下划线只落在每段**最后一项**（原站规律；克隆自首项会丢失，已按原样重放）
- 嵌套子条目：识别 `<ul>` 是嵌在 `<li>` 内还是与 `<li>` 同级两种结构，分别还原
- 空白条目过滤；无内容模块隐藏
- 一页适配：保留模板原始字号/行距/间距，不做字号档位压缩；页面高度取 `max(1123, 自然内容高度)`，长内容自然增高而非压缩

## 已知边界

- 超长内容模板（自然高度 > 一页）导出的 PDF/Word 单页会高于 A4，这是原站封面/下载件的真实形态；打印到 A4 时按“适应页面”缩放
- Word 导出为图片版（视觉一致、不可编辑文字）；经典 14 套模板仍保留可编辑结构化 Word
- 页面内的头像/示例图片仍引用原站 CDN；完全离线部署需再做资源本地化
- 模板切换为映射版式（14 套精选）时仍走经典渲染；4127 套采集模板走原站渲染
- 拖拽排序模块目前只影响经典渲染；原站 DOM 的模块顺序由模板决定
- 全量 4127 套逐像素审计因机器内存限制分批执行；批次结果记录在 `tools/audit/fidelity/`
