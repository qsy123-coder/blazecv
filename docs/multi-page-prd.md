# 多页排版 PRD（V2 第四期）

> 状态：已实现　｜　关联：`docs/resume-builder-prd.md`

## 背景与问题

V1 强制单页：内容超出一页时提示并裁切。真实简历、学术 CV、项目多的候选人都需要 2–3 页；裁切意味着内容丢失，无法交付。

## 目标

- 内容超出 A4 时自动分页，不再裁切
- 每页固定 A4（210×297mm），跨页保留页头（姓名 / 联系方式 / 模板页头）
- 优先在模块边界分页；单模块过高时按条目或段落拆分
- 预览显示页数、逐页标签；PDF 与预览页数一致
- PNG 逐页导出；分享页同样分页
- 版式与模板 token 保持一致，不因分页改变字体、颜色、间距

## 非目标

- 手动插入分页符 / 拖动分页位置
- 每页自定义页眉页脚或页码排版
- 孤行孤字级的行内断页控制（当前按模块/条目/段落级别）
- 超过 12 页的极端文档

## 方案

### 分页算法

1. 在屏幕外创建 210mm 宽的测量容器，用 React `createRoot` 渲染 `ResumePaper`
2. 用 `flushSync` 渲染候选文档，读取容器 `scrollHeight` 判断是否 ≤ A4 高度
3. 对当前剩余模块：
   - 全部放得下 → 作为一页
   - 否则找到能放下的最大模块前缀 → 作为一页，剩余进入下一页
   - 单个模块仍放不下 → 拆分：
     - 列表型模块（教育 / 工作 / 项目 / 技能 / 证书 / 自定义）：二分查找可放下的条目数，剩余条目生成「（续）」模块
     - 简介：二分查找可放下的字符数，优先在句号/换行处截断，剩余生成「（续）」
4. 最多 12 页；超限的剩余内容合并到最后一页（可能裁切）
5. 隐藏模块不参与分页；页头在每页重复

### 渲染

- 预览：纵向堆叠多个 `.page-frame`，每页 210×297mm，统一缩放，显示「第 n / N 页」
- 打印：独立 print sheet 渲染全部页面，每页 `break-after: page`，最后一页不强制断页
- PDF：浏览器打印 → 每页一张 A4
- PNG：逐页截图（2x DPR），文件名带 `-p1/-p2`
- Word：沿用 docx 自然流式分页
- 分享页：客户端使用同一分页 hook；未解锁的密码页不渲染内容

### 与旧单页逻辑的关系

- 移除「超出一页」警告与裁切
- 内容检查不再对多页扣分；页数在预览头部展示
- 溢出模块虚线标记逻辑保留在 DOM 但不再触发（分页后不再溢出）

## 一页适配

模板示例内容超出 A4 时，应用模板时自动调整排版参数，尽量落在单页：

1. 按压缩代价排序候选主题：优先缩行距（最低 1.2）、页边距（最低 6mm）、字号（大 → 标准 → 小 → 特小），最后启用紧凑模块间距
2. 隐藏容器中实际渲染候选主题，读取内容高度
3. 第一个 ≤ A4 高度（1123px + 2px 容差）的组合即采用
4. 排版参数用尽后，按 95% → 90% → 85% → 80% → 75% → 70% 逐级增加额外缩放（同时作用于字号与页边距）；第一个放得下的值即采用
5. 70% 仍放不下时保留多页分页
6. 编辑器「排版与主题 → 自动适配一页」可手动执行；模板库创建简历时自动执行
7. 用户手动修改字号/行距/页边距会清除额外缩放，避免叠加

验收：模板库抽样 56 套（7 种版式 × 8 套）均为 1 页；其中长内容模板启用额外缩放后在面板提示实际比例。

验收：模板库首个模板（应届生通用）在默认内容下为 1 页；压缩后仍保留原始内容，不删条目。

## 数据模型

- 不新增持久化字段；页面切片是运行时派生数据
- 每页仍是 `ResumeDoc` 子集：相同 basics/theme/template，`sections` 为当前页片段
- 拆分产生临时模块 ID：`<id>_cont_<pageIndex>`，标题追加「（续）」

## 边界与异常

| 场景 | 行为 |
|---|---|
| 单个条目高于整页 | 该条目独占一页并按页裁切（仍保留数据） |
| 简介超长 | 按字符二分 + 句号/换行截断，生成续段 |
| 模块刚好等于页高 | 视为可放下（容差 2px） |
| 隐藏模块 | 不进入分页与导出 |
| 编辑中 | 300ms 防抖后重新分页；期间显示旧排版与「排版中…」 |
| 超过 12 页 | 剩余内容并入最后一页 |
| 分享页首屏 | 先渲染单页，客户端分页完成后更新；打印始终使用分页结果 |
| 多页 PNG | 逐页触发下载，浏览器可能对连续下载做限制 |

## 验收标准

- [ ] 内容超过一页时自动生成第 2 页，预览显示「共 N 页」
- [ ] 每页内容高度不超过 A4（1123px + 2px 容差）
- [ ] 页头在每页重复，模板样式不变
- [ ] 模块边界优先断页；超高模块按条目/段落拆分并出现「（续）」
- [ ] PDF 页数与预览页数一致
- [ ] PNG 逐页导出，文件名含页码
- [ ] 分享页对多页内容同样分页、可打印
- [ ] `npm run verify` 覆盖多页预览、多页 PDF、多页 PNG

## 测试

`scripts/verify.mjs` 在商务蓝模板下：

- 放大字号、行距、页边距并写入 40 段简介
- 等待分页，断言页数 ≥2、每页内容高度 ≤1126
- `page.pdf()` 断言页数 ≥2
- 导出 PNG 并断言下载文件 ≥2
- 分享页创建、公开访问、密码与撤销保持通过

## 已知限制

- 分页在浏览器端完成，依赖实际字体渲染；不同系统字体可能导致页数与断点略有差异
- 侧栏 / 时间轴模板的后续页仍保留页头侧栏，但主内容按单栏续排；不重复技能栏
- 不做行级孤行控制，极长单条要点仍可能单独占页
