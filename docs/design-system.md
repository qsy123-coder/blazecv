# 简历模板设计系统

> 设计输入来自 StyleKit MCP（`https://www.stylekit.top/mcp`，MIT 资产），仅作为设计与校验依据，不引入运行时依赖。

## 依据

| StyleKit 资产 | 取用的规则 |
|---|---|
| `spacing/8pt` | 4 / 8 / 16 的间距节奏，页内边距与模块间距落在 4pt 网格上 |
| `type-scale/ratio-1-2` | 紧凑模板字阶比 1.2（Minor Third） |
| `type-scale/ratio-1-25` | 标准模板字阶比 1.25（Major Third） |
| `type-scale/ratio-1-333` | 学术风字阶比 1.333（Perfect Fourth） |
| `visual-hierarchy/text-primary` | 一级文字 700 字重、100% 不透明度 |
| `visual-hierarchy/text-secondary` | 二级文字 500 字重、约 90% 不透明度 |
| `visual-hierarchy/text-tertiary` | 元信息 400 字重、约 60% 不透明度 |
| `design-principle/contrast` | 层级差异必须明显，不做“似是而非”的弱对比 |
| `design-principle/alignment` | 日期右对齐、条目左对齐，共用同一条基线 |
| `design-principle/proximity` | 模块间距 > 条目间距，相关条目成组 |
| `design-principle/repetition` | 48 套模板共用同一套标题样式与间距节奏 |

## 设计 token

### 字阶

| 角色 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 姓名 | 21–24pt | 700 | `headingColor` |
| 求职意向 | 正文 +2pt | 400 | `primary` |
| 模块标题 | 11.5–13pt（正文 × 1.2 / 1.25 / 1.333） | 700 | `primary` |
| 条目标题（公司/学校） | 正文 | 600 | `headingColor` |
| 条目角色/专业 | 正文 | 400 | `muted` |
| 正文 | 9.5–10pt | 400 | `bodyColor` |
| 日期/地点/标签 | 正文 × 0.86–0.9 | 400 | `muted` |

### 间距

| 位置 | 标准模板 | 紧凑模板 |
|---|---|---|
| 模块间距 | 16px | 8px |
| 条目不透明度 | 8px | 6px |
| 模块标题下间距 | 8px | 4px |
| 条目内要点间距 | 4px | 2px |
| 要点与标题 | 4px | 4px |
| 页边距 | 16mm（可调 10–22mm） | 同左 |

### 层级与对齐

- 日期列右对齐（单栏/时间轴），与左栏共用基线；
- 侧栏模板的联系方式、技能、证书统一放左/右栏，主栏只放叙事型模块；
- 要点使用 60% 不透明度的圆点，避免与正文抢视觉重量；
- 标签使用 1px 边框 + muted 文字，字号 0.82em，不填充重色。

## 结构性规则

- **横幅页头**：姓名反白，职位与联系方式用 82–88% 白色；斜切页头底边下倾，正文与页头之间留 8–12mm。
- **深色侧栏**：侧栏文字 `#f8fafc`，次要信息 `#94a3b8`，强调色 `#38bdf8`；主栏仍用模板主色。
- **左右分栏**：姓名居中加 1.5px 框线，正文 1.1:1 分栏；窄栏启用日期堆叠，避免长校名挤压日期。
- **编辑标签栏**：左侧 28mm 固定标签列，右侧正文；姓名 28–30pt，联系方式右对齐。
- **技能条**：只有 `SkillItem.level`（1–5）存在时渲染；轨道为 4px，填充按 20% 递增；深色侧栏用强调色，浅色模板用主色。

## 验收清单

- [ ] 模块标题与正文有明显字号/字重跳变，不依赖颜色单独区分
- [ ] 姓名到正文至少 2 倍字号差
- [ ] 模块间距视觉上明显大于条目间距
- [ ] 同一条目内日期与标题基线对齐，长标题不挤压日期
- [ ] 要点圆点弱于正文，不形成第二视觉焦点
- [ ] 48 套模板的标题样式、间距节奏一致，只允许颜色/结构/字族差异
- [ ] 技能条仅在设置熟练度时出现，不渲染无依据的进度
- [ ] 打印 PDF 与预览在字号、间距、断行上一致
